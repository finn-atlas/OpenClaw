# Google Chat fork patch stack

This branch builds on upstream OpenClaw `main` at `85507ee907`. Each commit below is a separate layer so an upstream refresh can drop a layer as soon as upstream supplies the same behavior. The branch does not change other channel plugins.

This inventory covers the Google Chat overlay deployed to VOC. Fork `main` has independent prompt-reconciler and CI changes that are not in this overlay or the current VOC runtime. Reconcile those separately before promoting this branch to fork `main`; do not replace fork `main` with this branch.

The status layer does not turn `message(action=send)` into a placeholder edit. An explicit send remains a separate visible message; the monitor removes any unclaimed typing placeholder when that turn settles. Normal automatic final replies still replace the placeholder. [Upstream issue #127567](https://github.com/openclaw/openclaw/issues/127567) tracks the common placeholder-custody defect.
