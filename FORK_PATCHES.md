# Google Chat fork patch stack

This branch builds on upstream OpenClaw `main` at `85507ee907`. Each commit below is a separate layer so an upstream refresh can drop a layer as soon as upstream supplies the same behavior. The branch does not change other channel plugins.

| Order | Commit       | Behavior                                                                                                                                                                                                | Activation                                                               |
| ----- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 1     | `a3312d1974` | Isolate Google Chat group sessions by thread while retaining space routing and physical reply targets. Adapted from [upstream PR #68967](https://github.com/openclaw/openclaw/pull/68967).              | `channels.googlechat.accounts.<id>.sessionThread: true`; defaults off.   |
| 2     | `9cb6571b33` | Render CommonMark before `message(action=send)`, including bold and labeled links, and keep chunks in one thread.                                                                                       | All Google Chat message-tool sends.                                      |
| 3     | `56a62887be` | Preserve automatic reply threading across reply modes and format fallback text.                                                                                                                         | All Google Chat automatic replies.                                       |
| 4     | `6d8c40f48e` | Edit the typing placeholder with queued/tool status, suppress routine commentary delivery, remove transient progress and unclaimed placeholders, and let normal final delivery replace the placeholder. | `messages.statusReactions.enabled: true` and a message typing indicator. |
| 5     | `b831b5fe70` | Preserve batched reply routing and placeholder custody when a provider edit is definitively rejected.                                                                                                   | Google Chat reply delivery.                                              |
| 6     | `9250e5517c` | Avoid deleting a placeholder after an ambiguous edit timeout.                                                                                                                                           | Google Chat reply delivery.                                              |

The status layer does not turn `message(action=send)` into a placeholder edit. An explicit send remains a separate visible message; the monitor removes any unclaimed typing placeholder when that turn settles. Normal automatic final replies still replace the placeholder. [Upstream issue #127567](https://github.com/openclaw/openclaw/issues/127567) tracks the common placeholder-custody defect.
